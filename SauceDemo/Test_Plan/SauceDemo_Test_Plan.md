# SauceDemo Test Plan

## 1. Project Overview

This test plan outlines the manual testing approach for the SauceDemo web application. The objective is to verify that the core functionalities of the application work as expected and provide a seamless user experience.

---

## 2. Objective

The primary objective of this testing is to validate the functionality, usability, and reliability of the SauceDemo application by executing manual test cases on its core features.

---

## 3. Application Details

- **Application Name:** SauceDemo
- **Application URL:** https://www.saucedemo.com/
- **Application Type:** E-commerce Demo Web Application

---

## 4. Scope of Testing

### In Scope

- Login
- Product Inventory
- Product Details
- Product Sorting
- Add to Cart
- Remove from Cart
- Shopping Cart
- Checkout Process
- Order Confirmation
- Logout

### Out of Scope

- Database Testing
- API Testing
- Performance Testing
- Security Testing
- Cross-browser Testing
- Mobile Application Testing

---

## 5. Testing Types

- Functional Testing
- UI Testing
- Smoke Testing
- Regression Testing
- Exploratory Testing
- Negative Testing

---

## 6. Test Environment

- Operating System: Windows 11
- Browser: Google Chrome (Latest Stable Version)
- Test Type: Manual Testing

---

## 7. Entry Criteria

- Application is accessible.
- Test environment is available.
- Test data is prepared.

---

## 8. Exit Criteria

- All planned test cases are executed.
- Critical and High severity defects are resolved or documented.
- Test Summary Report is prepared.

---

## 9. Deliverables

- Test Plan
- Test Scenarios
- Test Cases
- Bug Reports
- Requirement Traceability Matrix (RTM)
- Test Execution Report
- Test Summary Report

---

## 10. Risks

- Demo application may become temporarily unavailable.
- Existing demo data may change.
- Internet connectivity issues.
